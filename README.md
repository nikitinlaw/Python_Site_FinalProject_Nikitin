## О проекте

Backend веб-сайта для размещения и поиска объявлений об аренде одежды.

## Реализовано

- регистрация, вход и профиль пользователя;
- размещение объявлений;
- загрузка фотографий;
- модерация новых объявлений;
- модерация изменений уже опубликованных объявлений;
- редактирование и удаление собственных объявлений;
- поиск по ключевым словам, местоположению и стоимости аренды;
- разделение ролей продавца, модератора и администратора;
- показ контактов владельца только авторизованным пользователям;
- отзывы и оценки;
- PostgreSQL;
- автоматические тесты.

## Технологии

- Python
- Django
- PostgreSQL
- psycopg
- Pillow
- python-dotenv

## Установка и запуск

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте файл `.env` на основе `.env.example` и укажите параметры подключения к PostgreSQL.

Примените миграции:

```bash
python manage.py migrate
```

При необходимости создайте администратора:

```bash
python manage.py createsuperuser
```

Запустите сервер разработки:

```bash
python manage.py runserver
```

Сайт будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

Административная панель:

```text
http://127.0.0.1:8000/admin/
```

## Тесты

Запуск автоматических тестов:

```bash
python manage.py test
```

В проекте реализованы тесты основных бизнес-сценариев: регистрации пользователей, модерации объявлений, ограничения доступа, редактирования через ревизии, контактов и отзывов.

## Примечание

Файл `.env` с паролем базы данных не хранится в репозитории. Для настройки используется `.env.example`.
